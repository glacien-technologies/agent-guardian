About AgentGuardian

AgentGuardian is an adversarial swarm framework for red-teaming agentic AI systems. Eleven specialist agents probe a target across the ten OWASP ASI categories; their findings combine into a deterministic AIVSS score aligned with MITRE ATLAS and the CSA Agentic Threat taxonomy.

Methodology

  • Recon: phase-1 fingerprint of the target surface.
  • Swarm: ten ASI specialists run in parallel under a commander with periodic AIVSS checkpoints.
  • Scoring: the AIVSS formula is purely deterministic — same findings, same score, every time.
