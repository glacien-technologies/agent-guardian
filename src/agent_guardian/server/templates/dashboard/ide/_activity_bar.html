{# Activity bar — 48px left rail with inline-SVG icons in the VS Code Codicons style. Buttons activate sidebar views (explorer / search / findings / trace) and the bottom slot opens the shared theme switcher. Each button toggles `data-active` on itself and dispatches a custom event so `ide_interactive.js` can update the file tree's render mode without a reload. Default-active is "explorer" — the file tree view. #}
