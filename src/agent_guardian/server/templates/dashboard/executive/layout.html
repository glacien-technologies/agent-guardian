{# Live SSE patcher — mirrors the other themes so the same /scans//live stream drives Executive's KPI strip identically. Snapshot-only updates; ``probes_list`` / ``logs_tail`` are NOT data-live (operator F5 refreshes). SSE Phase 1, Step 4 — the patcher now supports three modes via the ``data-live`` attribute prefix: * ``data-live=""`` — default ``text`` mode. Sets ``textContent`` to ``snapshot[key]`` (back-compat with every existing site). * ``data-live="attr::"`` — sets ``node[attr-name]`` to ``snapshot[key]``. Used by the BAND pill to recolor via a ``data-band=""`` attribute the CSS keys off. * ``data-live="pulse::"`` — sets ``textContent`` AND transiently toggles ```` on the node when the value changes. Used by the FINDINGS tile to flash on every increment. The ELAPSED tile keeps the plain ``data-live="elapsed"`` text mode so the ticker can take over on first snapshot. The ticker writes a ``data-elapsed-anchor`` attribute on the same node; once stamped, this patcher still wins on a divergence-freeze fallback because ``elapsed-ticker.js`` removes the anchor in that branch. #} {# SSE Phase 2, Step 2.4 — open the per-scan event stream and wire live-append. The ``/scans//live`` stream above carries snapshot-only patches (KPIs); the ``/scan//events`` stream carries the per-emit events (finding / agent_* / reflection) that live-append turns into row inserts. Two streams keep the snapshot vs. event-log split that's been the architecture since Phase 1. Skip on terminal scans (no producer left) and when the ``AGLiveAppend`` module hasn't loaded (defensive — defer order is guaranteed but the module guards anyway). #}
