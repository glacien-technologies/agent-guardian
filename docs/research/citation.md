# Cite AgentGuardian

> **TL;DR.** How to cite AgentGuardian in academic work. BibTeX and APA below; the canonical `CITATION.cff` is rendered verbatim so this page can't drift from the file GitHub picks up for the "Cite this repository" button.

## BibTeX

```bibtex
@software{agentguardian2026,
  author  = {{Glacien Pte. Ltd. Engineering}},
  title   = {{AgentGuardian: A Multi-Agent Adversarial Swarm for OWASP ASI-Aligned Red Teaming}},
  year    = {2026},
  version = {1.0.0},
  url     = {https://github.com/glacien-technologies/agent-guardian},
  license = {Apache-2.0}
}
```

Glacien Pte. Ltd. Engineering. (2026). *AgentGuardian: A Multi-Agent Adversarial Swarm for OWASP ASI-Aligned Red Teaming* (Version 1.0.0) [Software]. <https://github.com/glacien-technologies/agent-guardian>
