Phase 1 · Recon

Map the attack surface before attacking it

The recon-agent probes the target with a black-box capability audit — it makes the agent take observable actions and runs a planted-token memory test — then an LLM structures the transcript into a TargetFingerprint. Every downstream decision (which agents run, the tier, the score) keys off this.

Capability audit transcript
Phase 2 · Decompose

The Commander turns one goal into per-agent briefs

Recon's inferred goal is decomposed by the Commander LLM into a SwarmBrief — a priority weight + scenario budget per agent. Then the 10 ASI specialists are instantiated and each one's is_applicable() decides whether it has anything to do against this fingerprint.

Phase 3 · Parallel attack

Specialists attack concurrently

Applicable agents run in parallel under an asyncio TaskGroup. Each runs its own attack loop; a checkpoint task samples a provisional AIVSS the whole time. Watch goal-hijack-agent expanded below to see one agent's inner loop in detail.

Phase 6 · Finalise

Aggregate findings into the AIVSS verdict

All findings are collected from shared memory (an optional --pov-gate would replay each one to drop the unreproducible). compute_aivss() turns them into per-ASI sub-scores and one 0–100 number, token spend is priced into USD, and the signed Scan object is emitted.
