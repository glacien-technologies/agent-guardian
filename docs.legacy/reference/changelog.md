# Changelog

**TL;DR.** Every shipped change, newest at top. Mirrors the repo-root
[`CHANGELOG.md`](https://github.com/glacien-technologies/agent-guardian/blob/main/CHANGELOG.md)
verbatim — the same file the maintainers update at release time. For
breaking-change guidance see [reference / migration](migration.md).

The changelog format is loosely based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and the project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

!!! note "Maintainer-facing milestone prefixes"

    The `[1.1.0]` section's entries reference internal milestone prefixes
    (e.g. `M2`, `M3 §5.3`). Those are maintainer artefacts — they will
    be translated into user-facing labels when v1.1 ships. The mapping
    lives in [reference / roadmap — milestone decoder](roadmap.md#milestone-decoder-contributors).
