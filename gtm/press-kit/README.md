# Press kit

A minimal press kit for newsletter editors, conference organisers, and
anyone writing about AgentGuardian. Do not put marketing copy in here
— this is reference material.

## Contents

| File                  | Purpose                                                |
| --------------------- | ------------------------------------------------------ |
| `boilerplate.md`      | The 50-word, 100-word, and 200-word boilerplates.      |
| `fact-sheet.md`       | The structured facts (license, version, frameworks).   |
| `founder-bio.md`      | The 50-word and 200-word founder bio.                  |
| `LOGOS.md`            | Where to fetch the logo assets and brand guidance.     |

## Linking from outside

This directory is public and stable. Link to it as
`https://github.com/glacien-technologies/agent-guardian/tree/main/gtm/press-kit`
from cold emails, conference submissions, and partner integrations.

The logo files themselves live under `docs/images/` (not under
`gtm/press-kit/`) so the Mintlify docs and the press kit share a
single source of truth. `LOGOS.md` points there.
